# ⚖️ LawMemory (แอพท่องจำประมวลกฎหมายอาญา และแพ่งฯ)

แอพพลิเคชันสำหรับนักศึกษากฎหมาย ทนายความ และผู้เตรียมสอบเนติบัณฑิต/ผู้ช่วยผู้พิพากษา เพื่อการท่องจำบทบัญญัติและการวางหลักกฎหมายอย่างแม่นยำ ด้วยเกมพิมพ์ดีดไล่ระดับ 5 ระดับ และระบบทบทวน Spaced Repetition (SRS)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **คลังมาตรากฎหมาย (Law Library & Editor)**
   - บรรจุชุดมาตราสำคัญเริ่มต้นสำหรับประมวลกฎหมายอาญา (ป.อ.) ตามที่ระบุ: **ม.56, 59, 60, 61, 62, 67, 68, 69, 72, 80, 83, 84, 86**
   - มีชุดมาตราสำคัญของประมวลกฎหมายแพ่งและพาณิชย์ (ป.พ.พ.) เช่น **ม.15, 149, 420**
   - มีครบทั้ง **ชื่อเรียกมาตรา, ตัวบทเต็ม, คำอธิบายหลักเกณฑ์, และการวางหลักสำหรับท่องจำ**
   - **แก้ไขได้ทุกส่วน**: ผู้ใช้สามารถแก้ไขข้อความ "การวางหลัก" ให้ตรงกับสำนวนหรือคีย์เวิร์ดย่อที่ตนถนัดท่องจำได้
   - **เพิ่ม/ลบมาตราเองได้**: มีปุ่มเพิ่มมาตราใหม่พร้อมระบบแท็กและหมวดหมู่

2. **เกมพิมพ์ท่องจำ 5 ระดับ (Progressive 5-Level Typing Game)**
   - **เลเวล 1 (เปิดคำ 100%)**: มองเห็นตัวบทครบทุกคำ สำหรับอ่านทำความเข้าใจและซ้อมจังหวะพิมพ์
   - **เลเวล 2 (ซ่อน 25%)**: สุ่มซ่อนคำกระจายกันห่างๆ โดยคำที่ซ่อนจะไม่ติดกันเลย
   - **เลเวล 3 (ซ่อน 50%)**: ซ่อนคำแบบสลับตัวเว้นตัว (คำเว้นคำ) ดึงความจำโดยมีคำนำทางข้างเคียง
   - **เลเวล 4 (ซ่อน 75%)**: ซ่อนคำส่วนใหญ่ โดยเหลือ "คำหลัก (Anchor)" เป็นจุดสังเกตเป็นระยะ ไม่ซ่อนยาวเป็นพรืด
   - **เลเวล 5 (ซ่อน 100%)**: ซ่อนคำทั้งหมด พิมพ์ตัวบท/การวางหลักออกจากความจำล้วนๆ
   - รองรับการพิมพ์ภาษาไทยเต็มรูปแบบทั้งบนคอมพิวเตอร์และมือถือ/แท็บเล็ต
   - มีระบบเสียงพิมพ์ Mechanical Click, เสียงแจ้งเตือนพิมพ์ผิด และเสียงเฉลิมฉลองเมื่อผ่านด่าน (Web Audio API)
   - มีปุ่ม "💡 ดูคำใบ้" ช่วยเฉลยคำถัดไปเมื่อติดขัด

3. **ระบบติดตามความคืบหน้า & ทบทวน Spaced Repetition (SRS)**
   - ระบบคำนวณวันทบทวนอัตโนมัติ (เช่น 1 วัน, 3 วัน, 7 วัน, 14 วัน, 30 วัน) ตามระดับความแม่นยำและคะแนน
   - แสดงรายการ **"มาตราที่ต้องทบทวนวันนี้"** ชัดเจน พร้อมปุ่มลัดเข้าสู่การทบทวนทันที
   - ระบบ **Daily Streak 🔥** นับจำนวนวันท่องจำต่อเนื่องเพื่อสร้างวินัย
   - ตารางสถิติความเร็วการพิมพ์ (WPM) และความแม่นยำ (%)

4. **สำรองและกู้คืนข้อมูล (Backup & Restore)**
   - ส่งออกข้อมูลเป็นไฟล์ JSON เพื่อสำรองเก็บไว้ในเครื่องหรือแชร์กับเพื่อน
   - นำเข้าไฟล์ JSON กู้คืนได้ทันที
   - ปุ่มคืนค่าเริ่มต้น (Reset to default)

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: รันผ่านคำสั่ง Terminal (แนะนำ)
เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์:
```bash
./run.sh
```
คำสั่งจะเปิดเซิร์ฟเวอร์และเปิดบราวเซอร์ที่ `http://localhost:8000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Python
```bash
python3 -m http.server 8000
```
แล้วเปิดบราวเซอร์ไปที่: `http://localhost:8000`

### วิธีที่ 3: เปิดไฟล์ index.html โดยตรง
สามารถดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานในบราวเซอร์ เช่น Safari หรือ Chrome ได้ทันที
